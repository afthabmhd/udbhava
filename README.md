# Udbhava ’26 landing page

Responsive desktop and mobile hero based on the supplied references. The nebula is drawn as real Canvas 2D monospaced glyphs; no nebula image, gradient, shader, or particle library is used.

## Files

- `index.html` — page structure and accessible navigation
- `styles.css` — desktop/mobile layout and typography
- `src/nebula-engine.js` — the supplied engine from `UDBHAVA.html`, including its original Canvas 2D field and render loop
- `src/main.js` — mobile navigation

## Tune or add a nebula

The supplied engine builds one continuous eight-viewport nebula world behind the page. Its responsive path control points, density field and reveal timing are in `src/nebula-engine.js`.

The reference set only shows the landing hero, so the follow-on events area is a lightweight placeholder section. Replace its copy and links when the remaining page references/content are available.

## Assets to replace

No external image or logo assets were supplied. The wordmark is editable text, and the frame, separator lines and menu icon are CSS. Replace the wordmark with the official Udbhava logo when available. The page uses Space Grotesk and DM Mono with system fallbacks.
